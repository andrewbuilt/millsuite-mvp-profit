# MillSuite

Next.js + Supabase app for cabinet-shop estimating, scheduling, invoicing, and project management. Actively developed; solo build.

**New here? Read `CLAUDE.md` (how we work), then `STATE.md` (where things are).** Everything in `docs/archive/` is historical.

Local setup: `pnpm install`, set `.env.local` (Supabase + Anthropic + Stripe keys), `pnpm dev`.
